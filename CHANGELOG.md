# Changelog

## 0.1.0 — 2026-10-22

- Added bounded loopback TCP connect checks and limited non-authenticating HTTP/SSH/SMTP/FTP/TLS observations.
- Added selected HTTP security-header and cookie-attribute leads, without retaining cookie or redirect values.
- Added private JSON assessment artifacts and JSON, CSV, and escaped HTML report generation.
- Added validated output names, no-overwrite defaults, CSV formula mitigation, CI package build, and local integration coverage.
- Scope remains hard-coded to loopback; DNS, broad host discovery, complete TLS validation, and multi-host assessment orchestration remain unsupported.
