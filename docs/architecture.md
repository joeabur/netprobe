# Architecture

The flow is CLI parsing → safe YAML loading → strict target parsing/local-only policy → validated scope. Dry-run commands produce a JSON preview; `scan` performs selected TCP connect checks using bounded asyncio concurrency and emits structured port observations. `models.py` defines validated finding and assessment records.

The central invariant is fail-closed: scope membership is checked before socket calls, and targets outside localhost/127.0.0.0/8/::1/128 are rejected. The scanner accepts one host per invocation, no more than 64 unique ports, concurrency up to 16, and timeouts up to five seconds. The same validation function is used for dry-run and active scans; dry-run returns before any socket call. Service inspection is a single-port operation with bounded reads: HTTP sends a constant `HEAD /`, SSH/SMTP/FTP only read server greetings, and HTTPS records negotiated TLS version and a certificate fingerprint without validating trust. HTTP plugins use only observed headers and expose no cookie or redirect values; findings require validation. Active HTTP checks save exclusive mode-0600 JSON artifacts, rendered to JSON/CSV/escaped HTML with no-overwrite defaults. Reports cover stored HTTP checks only. DNS and full certificate validation are not implemented.
